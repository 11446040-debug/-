📚 校園二手課本與講義搜尋系統

1. 案例背景與解決問題

給誰使用： 大學生（買家與賣家）。

解決什麼問題： 傳統校園二手書買賣多依賴 FB 社團或 Line 群組，貼文容易被洗版，且無法進行多條件篩選。買家常需要花大量時間逐篇滑貼文，無法快速找到符合「特定預算」與「特定書況」的指定課本。本系統提供結構化的多條件 SQL 查詢介面，讓買家能快速進行交集搜尋。

2. 資料庫架構說明

系統包含兩張資料表：books（二手書籍）與 users（賣家資訊），透過 books.seller_id = users.id 關聯。

  • books 欄位： id, title (課本名稱), price (售價), condition (書況), status (販售狀態), seller_id
  • users 欄位： id, name (賣家姓名), contact (聯絡方式)

4. 查詢結果比較與分析說明

針對同一問題修改 SQL 的結果變化說明：

情境： 尋找「低於 300 元」且「全新」的資料庫課本。

  • 過濾嚴格的 SQL： SELECT * FROM books WHERE title LIKE '%資料庫%' AND price < 300 AND condition = '全新';
    ➔ 結果： 0 筆資料（條件過於嚴苛，庫存中沒有此組合）。
  • 修改後放寬條件的 SQL： SELECT * FROM books WHERE title LIKE '%資料庫%' AND price BETWEEN 300 AND 600 AND condition = '全新';
    ➔ 結果： 成功查到 1 筆金額為 $550 的全新課本。
  • 原因說明： 因為市場上「全新」課本價格通常較高，適度調高售價預算區間後，就能順利查詢到符合書況要求的書籍。
